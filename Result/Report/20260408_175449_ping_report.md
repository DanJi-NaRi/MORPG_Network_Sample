# 프로토콜 테스트 리포트: ping

## 목적
- C2S_Ping 요청에 대해 서버가 S2C_Pong으로 즉시 응답하는지와 왕복 지연(RTT)을 검증한다.

## 기대 동작
- 서버가 C2S_Ping 수신 직후 S2C_Pong을 전송한다.
- 응답의 reqTime 값이 요청의 reqTime 값과 동일해야 한다.

## 실행 명령
- C:\Project\MORPG_Network_Sample\Bin\x64\Debug\Server\YunoServer.exe 9000
- TcpClient connect 127.0.0.1:9000
- Send C2S_Ping(type=6, reqTime=1816996651)
